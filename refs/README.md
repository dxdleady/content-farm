# Референсы для генерации фонов

Складывай сюда картинки, на которые должна быть похожа генерация.

```
refs/style/     — эталоны. Всё, что тут лежит, уходит в модель как визуальный референс
                  вместе со STYLE LOCK. Формат: png / jpg / webp.
refs/rejected/  — «так не надо». Не отправляется в модель, лежит для нас, чтобы
                  сверяться глазами и правиться промпт.
```

Правила по `refs/style/`:

- **3–6 картинок максимум.** Больше — модель усредняет и получается каша.
- Клади только то, что реально описывает нужный слой: свет, зерно, палитру, композицию.
  Не клади скриншоты с текстом и UI — модель начнёт рисовать буквы.
- Имя файла ни на что не влияет, но удобнее держать осмысленное: `grain-warm.png`,
  `rings-indigo.jpg`.

Референсы подхватываются автоматически при следующем рендере. Кэш завязан на состав
папки, так что после добавления/удаления файла фоны перегенерируются сами.

Проверить, что видит пайплайн:

```bash
node src/bgen.mjs
```
